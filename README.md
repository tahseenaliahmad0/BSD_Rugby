# BSD Rugby video analysis

Self-hosted video analysis for the rugby programme: upload match footage,
watch it frame by frame, and (in later milestones) tag it, build playlists and
let AI propose tags. Runs on the college GPU server with Docker Compose. See
`docs/` for the design spec summary, the milestone plan and decision records.

Milestones 0 and 1 are in progress; this README is completed in that work.
